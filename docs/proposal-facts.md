## 项目简介

为 MoonBit 网络工具提供可嵌入的 DHCPv4 UDP 负载编解码、选项分片重组和结构诊断能力。输入真实报文字节，输出固定头、物理选项、逻辑值与诊断；也可从模型生成负载，供独立工具或设备测试消费。主体复杂度在 MoonBit 协议模型与语义处理，CLI 只提供文件边界。

## 核心功能范围

- 固定头、cookie、Pad/End/TLV 读写；已知字段宽度和报文资源限制。
- option 52 overload；按 options → file → sname 重组重复选项。
- 未知选项和不活动字段原始字节保留；UInt32 租期和地址列表访问。
- 明确区分解码成功、诊断错误、无效数据模型和资源耗尽。
- 实际文件 inspect/build/normalize CLI、跨后端测试和独立实现对照。

## 通用性与完整预期场景

1. 网络工具从 PCAP 库取得 DHCP UDP 负载，调用本库定位字段/选项错误，并提取地址、DNS、网关和租期，输出供排错消费的报告。
2. 协议测试工具从明确配置构造客户端消息，输出二进制文件，由 Scapy 等独立实现读取核对字段，供客户端兼容性与回归测试复用。
3. 设备模拟测试按既定 transaction ID 和配置生成 OFFER/ACK 回复负载，检查端到端字节/逻辑值往返，验证设备解析而不实际分配地址。

相关 MoonBit PCAP/UDP 库可供上游字节；本项目不重写抓包框架。现有索引查重未命中 DHCP/BOOTP 模块元数据，但不据此宣称生态绝无相关内部实现或需求已被外部用户证实。
